# Contributing

This repository is Niobium's fork of
[openfheorg/openfhe-development](https://github.com/openfheorg/openfhe-development). It carries changes Niobium needs
and is not a place to develop the project itself.

## Contributions belong upstream

If you want to improve the project, please contribute to the original:
**[github.com/openfheorg/openfhe-development](https://github.com/openfheorg/openfhe-development)**. Its maintainers
and its own contribution terms apply there.

This fork does **not** accept pull requests from outside Niobium.

## Issues

Open an issue here **only** if it is about a change Niobium made in this fork.
For anything that also happens in the original project, report it upstream.
You do not need to sign anything to open an issue.

## Reporting a security issue

Please do **not** open a public issue for a security vulnerability. If it
affects the original project, report it to its maintainers as they ask. If it
is in Niobium's changes, report it privately as described in
[SECURITY.md](SECURITY.md).
